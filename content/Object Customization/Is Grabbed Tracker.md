[[IsGrabbedTracker.cs]] is a script that attaches to any node type, and emits a signal (IsGrabbedTrackerUpdated) that other nodes can connect to be alerted when their parent grabbable object is grabbed and dropped. This is a requirement of many other object customizations. See [[IsGrabbedTracker.cs]] for API reference if you want to make custom nodes that connect to this.
