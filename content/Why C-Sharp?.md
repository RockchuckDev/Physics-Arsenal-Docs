C# (or C-Sharp) was chosen for this project because it is an industry standard language, and I already have experience with it from my time developing in Unity. Which basically means the skills I develop while working on this project can be useful in domains beyond game development. While GDScript has many incredible (some mind-blowing) benefits, being applicable beyond the Godot game engine is unfortunately not one of them. So GDScript was not used for this project, and C# was chosen instead.
