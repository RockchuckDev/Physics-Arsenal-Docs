# 1.0.0 Release Plans
- Interacting with grabbed objects
	- Such as firing a gun or consuming a potion
- Grab Point has behavior to account for two hands grabbing the same object
- "static_rotation" metadata tag. The object preserves the rotation it had in world space when it was picked up
- "no_rotation" metadata tag. The grabbed object has no rotational force applied to it, and hangs limply
- Everything works well in online multiplayer and is easy to get working
