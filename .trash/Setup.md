# Prerequisites
- You will need the .NET build of Godot Engine, as Physics Armory was programmed in C#. You can download it [here](https://godotengine.org/download/)
	- See [[Why C-Sharp?]] for the reasoning behind this decision
	- Physics Armory was built in Godot 4.7, and has yet to be tested with other versions of Godot
